# RATIB Contact Center — Live updates on rateb.sa

## Recommended: POLLING (default after deploy)
- No port 9702
- No Hetzner firewall rules for WebSocket
- No cron / rcc-realtime-hub.php required for Agent Desktop
- Inbox + AI Copilot refresh every 8 seconds over HTTPS (443)

.env (optional — polling is default in code):
  RCC_REALTIME_MODE=polling

## Optional: WebSocket (VPS / port 9702 open only)
  RCC_REALTIME_MODE=websocket
  RCC_WEBSOCKET_PORT=9702
  Run: ratib-contact-center/bin/start-realtime-hub.sh (cron every */5)

## Hetzner firewall (website only)
Keep inbound: HTTP 80, HTTPS 443 (+ DirectAdmin 2222 if needed).
You do NOT need 9701–9702 for polling mode.

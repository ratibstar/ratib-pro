**Do not** add ERP business logic, validation, or local databases here.

| `home/` | ESS dashboard |

| `payslips/` | Payslips |
| `notifications/` | Notifications |
| `profile/` | My profile |
| `approvals/` | Manager approvals (permission-gated) |

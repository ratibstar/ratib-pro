# تثبيت تطبيق RATEB HR على أندرويد

## أي ملف تختار؟

| الملف | متى تستخدمه |
|--------|-------------|
| **rateb-hr-agency-admin.rateb.sa-arm64.apk** | وكالة **admin.rateb.sa** (تجربة 2) — **الأفضل للوكالة** |
| **rateb-hr-platform-rateb.sa-universal.apk** | منصة **rateb.sa** (شركات على المنصة الرئيسية) |

> ملف arm64 أصغر (~36 MB) ويناسب معظم الهواتف الحديثة.  
> Universal (~57 MB) يعمل على أجهزة أكثر لكن حجمه أكبر.

APK جاهز بعد البناء في: `ratib_hr_mobile/dist/android/`

---

## التثبيت من الجوال (بدون كابل)

1. انسخ ملف `.apk` إلى الجوال (WhatsApp / Drive / USB).
2. **الإعدادات → الأمان → تثبيت تطبيقات غير معروفة** — فعّل للتطبيق الذي تفتح منه الملف.
3. افتح الملف → **تثبيت** → **فتح**.
4. سجّل الدخول بـ **البريد** و**كلمة المرور** (حساب موظف مرتبط بالشركة).

---

## التثبيت من الكمبيوتر (USB)

```powershell
cd ratib_hr_mobile
.\tool\install_android.ps1
```

---

## بعد التثبيت

- **البصمة:** المزيد → الإعدادات → تسجيل الدخول بالبصمة.
- **طرق الدفع / الشكاوى:** اسحب للتحديث داخل الصفحة بعد أول دخول.
- **تحديث:** ثبّت APK الجديد فوق القديم (نفس الاسم).

---

## إعادة بناء الحزمة

```powershell
cd ratib_hr_mobile
.\tool\build_android_release_pack.ps1
```

وكالة فقط:

```powershell
.\tool\build_android_release_pack.ps1 -AgencyOnly
```

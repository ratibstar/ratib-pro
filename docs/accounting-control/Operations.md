# Operations

## Daily monitoring

- **Dashboard** — event volume, replay rate, drift trend
- **Notifications** — replay/projection/consolidation/drift alerts from audit log
- **Health** — feature flags and table existence

## Common tasks

| Task | Screen |
|------|--------|
| Reprocess failed events | Replay → Replay failed |
| Rebuild financial snapshots | Projections → Rebuild snapshot |
| Run HQ consolidation | Consolidation → Run |
| Detect ledger drift | Drift → Run detection |
| Review corrections | Reconciliation → workflow KPIs |
| Audit readiness | Integrity → score + evidence packs |

## Exports

Use toolbar **Export** menu: CSV, Excel, JSON, PDF (print HTML).

## Filters

Company, branch, date range apply to all sections. Click **Apply** after changing filters.

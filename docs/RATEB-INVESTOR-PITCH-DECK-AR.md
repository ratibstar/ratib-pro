# دليل سريع: كيف تحوّله إلى PowerPoint

### الخطوات (10 دقائق)

1. افتح **PowerPoint** → قالب **Dark** أو **Simple** (16:9).
2. **Design → Slide Size → Widescreen (16:9)**.
3. لكل قسم `## الشريحة N` أعلاه:
   - **Title and Content** layout
   - العنوان = **العنوان** في الملف
   - النقاط = **النقاط** (3–5 bullets max per slide)
4. الشريحة 4: **Insert → SmartArt → Process** للمخطط.
5. الشريحة 5 و 7 و 8: **Insert → Table** من الجداول في الملف.
6. ألوان مقترحة (match enterprise tokens):
   - Primary: `#a855f7` (بنفسجي RATEB)
   - Background: `#0f0a1a` أو `#1a1025`
   - Text: `#f8fafc`
7. **Slide Master:** ضع logo + رقم الشريحة في الأسفل.
8. **Export PDF** للإرسال قبل الاجتماع.

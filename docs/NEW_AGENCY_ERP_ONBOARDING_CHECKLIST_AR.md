# قائمة تحقق: وكالة ERP جديدة (من الألف للياء)

**الوكالة = الشركة** (نفس العميل).  
تُضاف من **لوحة التحكم → إدارة الوكالات**، وتظهر تلقائياً في ERP → الشركات.

---

## 1) الدومين والاستضافة

- [ ] تجهيز الدومين + DNS + SSL
- [ ] Document root = جذر مشروع Rateb

## 2) قاعدة البيانات المستقلة

- [ ] إنشاء قاعدة MySQL + مستخدم للوكالة
- [ ] توثيق host / port / user / password / db name

## 3) لوحة التحكم → إدارة الوكالات

- [ ] إنشاء الوكالة (الاسم، الدولة، Site URL، DB / ERP DB)
- [ ] الحالة: نشط
- [ ] **Provision ERP** حتى تكون الحالة `ready`

## 4) ERP المنصة → الشركات

- [ ] افتح قائمة الشركات: تظهر الوكالة تلقائياً (بدون إنشاء يدوي ثانٍ)
- [ ] من **تعديل**: الباقة، صلاحيات الوحدات، حساب الدخول إن لزم
- [ ] الربط `erp_company_id` يتم تلقائياً عند فتح القائمة

## 5) تسليم العميل

| البند | القيمة |
|--------|--------|
| الرابط | دومين الوكالة |
| الدخول | `admin` / كلمة المرور الافتراضية بعد التوفير — غيّروها فوراً |

# قائمة تحقق: وكالة ERP جديدة (من الألف للياء)

المسار المعتمد: **وكالة بدومين + ERP منفصل + قاعدة مستقلة**.  
لا تنشئ العميل من ERP → الشركات على rateb.sa (إلا وضع صيانة).

---

## 1) الدومين والاستضافة

- [ ] شراء/تجهيز الدومين (مثال: `https://client.example.com`)
- [ ] DNS: `A` / `www` يشير لخادم Rateb
- [ ] إضافة الدومين في cPanel (Addon/Alias) على نفس حساب الاستضافة
- [ ] Document root = جذر مشروع Rateb
- [ ] شهادة SSL صالحة على `https://…`

## 2) قاعدة البيانات (ERP المستقلة)

- [ ] إنشاء قاعدة MySQL جديدة للوكالة
- [ ] إنشاء مستخدم DB وربطه بالقاعدة بصلاحيات كاملة
- [ ] توثيق القيم بدقة: host / port / user / password / database name

## 3) لوحة التحكم → إدارة الوكالات

- [ ] إنشاء وكالة جديدة (الدولة صحيحة)
- [ ] **Site URL** = رابط الدومين بالضبط (مع `https://`)
- [ ] تعبئة بيانات DB الخاصة بالـ ERP (`erp_*` إن ظهرت في النموذج)
- [ ] الحالة: **نشط** وغير موقوف
- [ ] حفظ السجل

## 4) تفعيل ERP

- [ ] من قائمة إجراءات الوكالة: **Provision ERP** (أو Re-provision عند إعادة التهيئة فقط)
- [ ] انتظار اكتمال التفعيل حتى يظهر ERP Status ≈ `ready`
- [ ] عند إعادة التوفير: يُزرع حساب افتراضي `admin` / `123456` — غيّروه فوراً بعد التسليم

## 5) اختبار الفتح والتسليم

- [ ] من الوكالة: زر **Open / ERP** يفتح دومين الوكالة
- [ ] صفحة الدخول على دومين الوكالة تعمل
- [ ] تسجيل الدخول: المستخدم `admin` وكلمة المرور الافتراضية (ثم التغيير فوراً)
- [ ] التحقق أن البيانات من قاعدة الوكالة وليس منصة rateb.sa

## 6) تسليم العميل

سلّم للعميل فقط:

| البند | القيمة |
|--------|--------|
| رابط النظام | `https://دومين-الوكالة/…` (دخول ERP) |
| اسم المستخدم | `admin` (أو ما غيّرتموه بعد التفعيل) |
| كلمة المرور | الافتراضية ثم يغيّرها العميل فوراً |
| ملاحظة | لا تستخدموا قائمة «الشركات» على rateb.sa لإنشاء وكالة جديدة |

## 7) صيانة المنصة (اختياري نادراً)

إن احتجتم إنشاء سجل شركة على rateb.sa للصيانة/الربط:

1. ادخلوا كمدير نظام
2. افتحوا: `…/admin/companies?company_create_maintenance=1`
3. أنشئوا السجل إن لزم
4. أوقفوا: `?company_create_maintenance=0`

أو ضعوا مؤقتاً في البيئة: `RATEB_ALLOW_PLATFORM_COMPANY_CREATE=1`

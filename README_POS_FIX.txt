📋 ملخص سريع: سبب عدم فتح شاشة البيع
================================================

❌ المشكلة الرئيسية:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ❌ MySQLi Extension غير محمل في PHP 8.4
   - الخطأ في السجلات: "Class "mysqli" not found"
   - الحل: تفعيل MySQLi في php.ini

2. ❌ خادم MySQL غير متاح (رفع الاتصال)
   - الخطأ: "No connection could be made because the target machine actively refused it"
   - الحل: تشغيل خادم MySQL

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


✅ خطوات الحل السريعة:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

الطريقة 1️⃣: استخدام أداة الإصلاح التلقائية
┌─────────────────────────────────────────────────┐
│ 1. افتح PowerShell كمسؤول                      │
│ 2. انتقل إلى مجلد المشروع                      │
│ 3. شغّل الأمر:                                  │
│    .\fix-pos-screen.ps1                        │
│                                                 │
│ ستقوم الأداة بـ:                               │
│ ✓ فحص امتدادات PHP                             │
│ ✓ تفعيل MySQLi                                  │
│ ✓ تشغيل خادم MySQL                             │
│ ✓ اختبار الاتصال                               │
│ ✓ مسح الذاكرة المؤقتة                          │
└─────────────────────────────────────────────────┘


الطريقة 2️⃣: الحل اليدوي (مع XAMPP)
┌─────────────────────────────────────────────────┐
│ 1. افتح ملف: C:\xampp\php.ini                  │
│ 2. ابحث عن السطر: ;extension=mysqli            │
│ 3. أزل الفاصلة المنقوطة: extension=mysqli     │
│ 4. احفظ الملف (Ctrl+S)                         │
│ 5. أعد تشغيل Apache من لوحة XAMPP             │
│ 6. تأكد من تشغيل MySQL من لوحة XAMPP          │
│ 7. افتح شاشة البيع في المتصفح                  │
└─────────────────────────────────────────────────┘


الطريقة 3️⃣: الحل اليدوي (مع Laragon)
┌─────────────────────────────────────────────────┐
│ 1. افتح Laragon                                │
│ 2. اذهب إلى: Quick settings > PHP              │
│ 3. تأكد من تفعيل: mysqli                       │
│ 4. أعد تشغيل All Services                      │
│ 5. افتح شاشة البيع في المتصفح                  │
└─────────────────────────────────────────────────┘


الطريقة 4️⃣: التحقق من الاتصال
┌─────────────────────────────────────────────────┐
│ 1. افتح PowerShell في مجلد المشروع            │
│ 2. شغّل:                                       │
│    php diagnose-pos-issue.php                  │
│                                                 │
│ النتيجة الناجحة:                              │
│ {                                               │
│   "extensions": {                               │
│     "mysqli": {"loaded": true},                │
│     "pdo": {"loaded": true},                   │
│     "pdo_mysql": {"loaded": true}              │
│   },                                            │
│   "database": {                                 │
│     "status": "ok"                             │
│   }                                             │
│ }                                               │
└─────────────────────────────────────────────────┘

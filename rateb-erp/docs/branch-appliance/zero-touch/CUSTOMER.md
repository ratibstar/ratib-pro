# RATIB ERP — Customer guide (Zero-Touch)

1. Download the installer for your computer.  
2. Run it and wait until it finishes.  
3. Double-click **RATIB ERP** on the desktop.  
4. Sign in and work.

The green / red light shows whether the cloud is available.

- **Green (online)** — opens `https://rateb.sa/rateb-erp/public/admin/`
- **Red (offline)** — opens `http://127.0.0.1:8088/admin` on this computer

The address switches automatically with the light. If the internet drops, keep working on the local address — your data stays on this computer and syncs when the connection returns.

You never need to install PHP, edit settings files, or start services manually.

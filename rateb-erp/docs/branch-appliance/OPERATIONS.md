# Operations Guide

| Task | Command |
|------|---------|
| Diagnostics | `php bin/hybrid-branch-diagnostics.php` |
| Health (once) | `php bin/hybrid-branch-health.php --once` |
| Register | `php bin/hybrid-branch-register.php` |
| Backup | `php bin/hybrid-branch-backup.php` |
| Restore | `php bin/hybrid-branch-backup.php restore <path>` |
| Recover | `php bin/hybrid-branch-recover.php` |
| Certify | `php bin/hybrid-branch-certify.php` |
| Sync service | `php bin/hybrid-sync-service.php` |

Logs: `storage/branch/logs/`, `storage/branch/health/`, `storage/branch/diagnostics/`.
